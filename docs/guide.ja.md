# Polyhedraverse の使い方

Polyhedraverse とその双子の [Rhombiverse](https://rhombiverse.vercel.app) は、同じ幾何学を 2 つの見方で眺めるサイトです。Rhombiverse は**風景**：あらゆる方向へ広がる格子そのもの。Polyhedraverse は**肖像画ギャラリー**：その格子に住む形を、1 つずつ間近で見せます。

ここには格子はありません。1 つの形から始めて、頂点どうし、面どうしで別の形をつなげていくと、形そのものから構造が生まれます。いくつかの形は、本物の 4D 多胞体へとセルを 1 つずつ組み上げることもできます。

このガイドの前半ではよく使う操作を順に説明し、後半ではすべての操作を一覧にしています。

画面上のボタン名は、アプリに表示されるとおりに書いています（アプリがまだ翻訳していないものは英語のままです）。形やファミリーの名前は、どの言語でも元の名前のままです。

## はじめに

### 形を選ぶ

1. ようこそ画面で **ENTER** を押します。
2. **Tab** か **Space** を押すか、**シェイプホイール** のボタンをタップして、シェイプホイールを開きます。
3. ホイールは十二面体で、各面が形のファミリーです。ドラッグで回し（矢印キーでも回せます）、面をタップするとそのファミリーが開きます。面にカーソルを合わせるか長押しすると名前が表示されます。ファミリーの中では、**Home** の面（六角形に H）でファミリー一覧に戻れます。
4. 形をタップします。画面上のものと入れ替わるので、まっさらな状態から始まります。

**ホイールを回す** はファミリーをランダムに選びます。

### カメラを動かす

- **回転：** 1 本指でドラッグ、またはマウスの左ボタンでドラッグ。
- **ズーム：** ピンチ、またはスクロールホイール。

### 面に形をつなげる

1. 形の本体をタップして選択します。タップした面も選択されます。
2. **Attach via face…** をタップします。ピッカーには、同じ大きさの面を持つ形だけが出てきます。
3. 新しい形が現れますが、まだ固定されていません。ドラッグで向きを変えてから **Confirm** をタップするか、**Cancel**（または Esc）を押します。

面どうしでつないだ 2 つの形は、その面をぴったり共有します。たとえば立方体の上の立方体です。

### 頂点に形をつなげる

1. **光っている頂点** をタップします。光るのは空いている頂点だけです。まだつなげる余地のある形は光ります。
2. **Attach via vertex…** をタップして、好きな形を選びます。頂点の結合はどんな形でも受け付けます。
3. 面のときと同じように、向きを変えて **Confirm** をタップします。

### 取り消しと削除

- **Undo**（↶、上部バー）は、直前の変更を種類を問わず取り消します：つなげる、削除、Transform、4D の組み立て、Start over、インポート。もう一度タップするとさらにさかのぼり、押し続けると何段階も一度に戻れます。
- 形を選んで **Delete** をタップすると、その形と、その上に作ったものがまとめて取り除かれます。

## カタログを見る

**シェイプブラウザ**（コーナーホイールの ◈）がギャラリーです。次のタブがあります：

- **ホーム：** ファミリーと、最近見た形、お気に入り。
- **検索：** 名前で検索（「J12」や「gyrobicupola」を試してみてください）するか、ファミリー、面の形、面の数で絞り込みます。
- **シーン：** これまでに作ったもの。
- **お気に入り：** 星を付けた形。

どの形もタップすると詳細が表示されます：頂点、辺、面、コネクタ。そこから次のことができます：

- **シーンに追加：** その形で作り始める。
- **お気に入り：** 星を付ける。
- **比較に追加：** 最大 4 つの形を並べて比べる。
- **4Dを見る：** 4D に対応した形で、その形が広がっていく 4D 多胞体を表示する。

### ファミリー

| ファミリー | 内容 |
|---|---|
| Deltahedra | 正三角形だけでできた 8 つの凸多面体 |
| Platonic | 5 つの正多面体 |
| Archimedean | 13 の半正多面体 |
| Johnson | 正多角形の面を持つ 92 の凸多面体 |
| Catalan | アルキメデスの立体の双対 |
| Prisms、Antiprisms | 2 つの多角形を正方形または三角形の帯でつないだもの |
| 4D-Capable | 閉じると正則な 4D 多胞体になる形 |
| Parallelohedra | 平行移動だけで空間を埋める形 |
| Space-Filling Pairs | 2 つ一緒に空間を埋める形 |
| Miscellaneous | 段階的なピラミッド、コネクタ用のピース、角柱の延長パーツ |

星形多面体も載っています。面どうしが互いを突き抜けているので、見るだけで、組み立てには使えません。

## 作品を眺める

**View** をタップすると、3 つのモードを順に切り替えます：

- **Solid：** 普通の面。
- **Translucent：** 透けて見える面。
- **Inside view：** 辺だけを表示するので、入れ子になった構造の内側が見えます。

いくつかのピースが閉じて完全なかごになると、**Closed cage!** と表示されます。よく知られた配置には、Stella Octangula のように名前が付きます。名前の横の **i** をタップすると説明が出ます。

## 4D で組み立てる

いくつかの形は正則な 4D 多胞体の構成単位です。たとえば立方体（テッセラクト）や十二面体（120 胞体）です。こうした形を選ぶと **3D / 4D** の切り替えが表示されます。

1. 形を選んで **4D** をタップします。閉じてできる多胞体が複数あるときは、どれにするか選びます。
2. **Add next cell** をタップすると、最初のセルのまわりにセルが 1 つずつ追加されます。**Remove last cell** で 1 つ戻せます。
3. 最初の殻が完成すると、**Build next shell** で層をまるごと 1 つ追加できます。**Remove last shell** で 1 層取り除きます。
4. カウンターには、全体のうちいくつのセルを作ったかが表示されます。

組み立てながら見てほしいもの：

- **Open / Closed：** Open は各セルをゆがみのない普通のコピーとして並べ、セルのあいだの本当のすき間が見えます。Closed は各セルを 4D 構造の中の本来の位置へ曲げて表示します。2 つ目の殻を作るとこの切り替えはロックされます。その殻は、最初の殻が閉じていることを前提にしているためです。
- **RCP-Coordinates：** 各セルの生成元になる点を紫の点で表示します。
- **Shell colours：** 殻ごとに色を変え、隣り合う殻を見分けやすくします。

**3D** をタップすると普段の操作に戻ります。4D の作品はそのまま残ります。

いくつかの形では **Attach via Duoprism…** も使えます。角柱を介して同じ形のコピーをつなぐ、4D Prism の構成です。

## 作品を保存する

- **Save：** 作品をこのブラウザに保存します。同じ端末・同じブラウザでサイトを開き直すと元に戻ります。
- **File → Export JSON：** 作品をファイルとしてダウンロードします。バックアップや、別の端末への移動に使えます。
- **File → Import JSON…：** 以前エクスポートしたファイルを開きます。画面上のものと入れ替わり、**Undo** で取り消せます。
- **What's New：** 最近の変更。
- **言語：** ようこそ画面やこのガイドの上部にある 🌐 ピッカーを使うか、コーナーホイールの 🌐 の面をタップして次の言語に進みます。7 つの言語があり、どこで変えても揃って切り替わります。

# 操作一覧

## 上部バー

| 操作 | 内容 |
|---|---|
| i | 名前の付いた配置の説明 |
| What's New | 最近の変更 |
| View | Solid、Translucent、Inside view を順に切り替え |
| ↶ Undo | 直前の変更を種類を問わず取り消し。もう一度タップでさらに戻り、押し続けると何段階も戻る |
| Save | 作品をこのブラウザに保存 |
| File ▾ | Export JSON、Import JSON… |

## コンテキストバー

ここの操作は、選んでいるものによって変わります。

| 状態 | 操作 |
|---|---|
| 形を選んでいるとき | Transform to…（関連する形があるとき）、Delete、Attach via face…、Attach via Duoprism… |
| 頂点を選んでいるとき | Attach via vertex… |
| 4D 対応の形を選んでいるとき | 3D / 4D、4D では Add next cell、Remove last cell、Build next shell、Remove last shell、Open / Closed、RCP-Coordinates、Shell colours |
| 新しい形の配置待ちのとき | Confirm、Cancel (Esc) |

## コーナーホイール

隅の小さな十二面体です。ドラッグで回し、面をタップします。

| 記号 | 操作 |
|---|---|
| ◐ | シェイプホイールを開く・閉じる |
| ◈ | シェイプブラウザを開く・閉じる |
| ⛶ | 表示モード |
| ▣ | Save |
| ℹ | About（ようこそ画面を再表示） |
| 🌐 | 次の言語に切り替え（いまの言語名を表示） |

## キーボードとマウス

| 入力 | 動作 |
|---|---|
| 形をクリック | 選択（クリックした面も選択） |
| 頂点をクリック | 頂点でつなげるために選択 |
| 左ドラッグ | カメラを回転、または確定前の新しい形の向きを変える |
| スクロールホイール | ズーム |
| Tab または Space | シェイプホイールを開く |
| Esc | 形の配置を取り消す、またはホイールを閉じる |

## タッチ

| ジェスチャー | 動作 |
|---|---|
| 頂点や形をタップ | 選択 |
| 1 本指でドラッグ | カメラを回転、または新しい形の向きを変える |
| ピンチ | ズーム |
