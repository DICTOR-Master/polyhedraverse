# Stage 6 — The Latent Reflection-Group Question (Question B)

## 1. Why this file picks a specific interpretation

`hypothesis.md` §11 asks: *"What geometric structure, if any, is
generated by the complete RD-derived mirror system?"* — deliberately
independent of whether it reproduces any known 4D closure (that's
Question A, already answered by Stages 2–5).

`hypothesis.md` §12's own seven steps describe lifting a SPECIFIC
aggregate's exposed facets into 4D via the RCP map before computing
angles. That lift needs a `θ` the way each of the four already-verified
regular seeds has one (tetrahedron/cube/octahedron/dodecahedron —
`radialProjection.ts`'s `FOUR_D_SHAPE_PARAMS`) — but a composite
aggregate has no such θ; inventing one would be exactly the kind of
"silently re-derived from memory" the investigation plan's own
verification caveat warns against.

This file instead answers the reading of §11 that doesn't require that
missing θ: **the RD's own 12 facet-normal directions (Δ_RD), used as
mirror planes through the origin in 3D** — an intrinsic property of the
RD cell itself, not of any one boundary-selection aggregate. This has a
real advantage beyond avoiding the missing-θ problem: any group
generated by finitely many reflections through the origin in R³ with
rational/algebraic (here ⟨110⟩-type) normals is a subgroup of a KNOWN
finite point group — it is mathematically GUARANTEED to close after
boundedly many steps. This sidesteps the investigation plan's own
Stage 6 warning about needing to "run orbit growth to enough depth to
distinguish slow finite convergence from genuine unboundedness" — that
warning applies to a genuinely open-ended search; this one isn't.

## 2. What was computed

`app/lib/polyhedra/composite-seed-rcp/reflectionGroup.ts`,
run by `scripts/verify-composite-seed-reflection-group.ts`:

1. **Δ_RD's 12 directions collapse to exactly 6 distinct mirror
   planes** — checked directly (`v` and `-v` produce the identical
   reflection matrix, since `I − 2mmᵀ` doesn't change sign with `m`).
2. **Group closure** (BFS over matrix products from the identity):
   terminates at **order 24**, well under the 200-element safety cap —
   confirms finiteness by direct computation, not assumption.
3. **Orbit test**, independently: a genuinely generic point's orbit
   under the closed group has size 24 (matches the group order exactly
   — trivial stabilizer, as expected for a generic point); a point
   deliberately placed ON one mirror plane has a smaller orbit (12 —
   nontrivial stabilizer), confirming the machinery behaves like real
   reflection geometry, not just producing a number.
4. **Determinant split**: exactly 12 elements with `det=+1` (proper
   rotations) and 12 with `det=-1` (improper) — rules out the pure-
   rotation octahedral group `O` (order 24, all `det=+1`) and is
   consistent with **`T_d`, the full tetrahedral point group** (order
   24, isomorphic to `S_4`).
5. **Pairwise angles** among the 6 mirrors: every pair is at either
   60° (`m=3`) or 90° (`m=2`) — both individually Coxeter-compatible.

## 3. The Gram-matrix subtlety (a real finding about the presentation, not a bug)

The idealized Gram matrix (`G_ij = -cos(π/m_ij)` for all 6×6 pairs) has
eigenvalues `[-1, 1, 1, 1, 2, 2]` — one negative. The standard
"Gram matrix positive-definite ⟺ finite Coxeter group" theorem would
seem to say this is evidence AGAINST finiteness. **It is not, and this
is a real, worth-recording structural fact rather than an ambiguity
left unresolved:** that theorem assumes a MINIMAL, linearly-independent
generating set. The RD's own 6 facet-normal directions in R³ are
necessarily linearly DEPENDENT (6 vectors can't be independent in a
3-dimensional space), so 6 is a redundant presentation of a group whose
actual minimal Coxeter rank is 3, not 6 (order-24 `T_d` has a standard
rank-3 presentation, e.g. as the `A_3` Coxeter diagram underlying
`S_4`). Applying the positive-definiteness theorem to a deliberately
redundant, over-determined generating set produces exactly this kind of
spurious negative eigenvalue — it does not contradict the direct
closure/orbit computation above, which already proved finiteness (order
24) unambiguously and independently of this matrix. The REAL (measured,
non-idealized) Gram matrix of the actual 6 vectors is, as it must be
for any real vectors, positive semi-definite of rank ≤3 — a sanity
check on the vector data, not an independent finiteness test (it would
be positive semi-definite regardless of whether the generated group
were finite or infinite, so it cannot itself decide the question).

## 4. Conclusion for this reading of Question B

**The RD's own intrinsic ⟨110⟩ mirror system generates a genuinely
finite reflection group of order 24, matching `T_d` (the full
tetrahedral point group).** This is not a novel or exotic structure —
`T_d` is one of the standard crystallographic point groups, and its
appearance here follows directly from the RD's own well-known cubic/
octahedral heritage (its facet normals are the diagonal mirrors of the
cubic lattice's own symmetry group `O_h`, order 48; using only the 6
"diagonal" ⟨110⟩ mirrors without the 3 axis-aligned ⟨100⟩ ones yields
exactly the index-2 subgroup `T_d`). This is a clean, complete,
unambiguous answer for THIS specific interpretation of Question B —
finite, not infinite, not inconclusive.

## 5. What remains genuinely open

The OTHER reading (§12's literal aggregate-specific 4D lift, using
some as-yet-undefined θ for a composite seed) is not answered by this
file and is not claimed to be. If a principled way to define that θ
for a composite aggregate is found later, that is a separate,
still-open follow-up — this file resolves the intrinsic-RD-mirror-
system reading of Question B, not every possible reading of it.
