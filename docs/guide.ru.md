# Руководство пользователя Polyhedraverse

Polyhedraverse и его близнец, [Rhombiverse](https://rhombiverse.vercel.app), — два способа смотреть на одну и ту же геометрию. Rhombiverse — это **пейзаж**: сами решётки, уходящие во все стороны. Polyhedraverse — это **портретная галерея**: фигуры, которые живут в этих решётках, по одной и крупным планом.

Здесь нет решётки. Вы начинаете с одной фигуры и присоединяете к ней другие — вершина к вершине или грань к грани, — и структура возникает из самих фигур. Некоторые фигуры можно также достроить до их настоящего 4D-многогранника, ячейка за ячейкой.

Первая часть руководства проводит по обычным действиям. Вторая перечисляет все элементы управления.

Названия кнопок приведены так, как они выглядят в приложении (те, что приложение пока не переводит, остаются на английском). Названия фигур и семейств на всех языках остаются в исходном виде.

## Начало работы

### Выберите фигуру

1. Нажмите **ENTER** на экране приветствия.
2. Нажмите **Tab** или **Пробел** либо коснитесь кнопки **колеса фигур**, чтобы открыть колесо фигур.
3. Колесо — это додекаэдр. Каждая грань — семейство фигур. Перетаскивайте, чтобы повернуть его (или используйте клавиши со стрелками), и коснитесь грани, чтобы открыть это семейство. Наведите курсор на грань или удерживайте её, чтобы увидеть название. Внутри семейства грань **Home** (буква H в шестиугольнике) возвращает к списку семейств.
4. Коснитесь фигуры. Она заменяет то, что было на экране, так что вы начинаете с чистого листа.

**Вращать колесо** выбирает семейство наугад.

### Двигайте камеру

- **Поворот:** перетаскивайте одним пальцем или левой кнопкой мыши.
- **Масштаб:** сведите или разведите пальцы, или прокрутите колёсико мыши.

### Присоедините фигуру к грани

1. Коснитесь тела фигуры, чтобы выбрать её. Грань, которой вы коснулись, тоже выбирается.
2. Коснитесь **Attach via face…**. В списке будут только фигуры, у которых есть грань того же размера.
3. Новая фигура появляется, но ещё не закреплена. Перетаскивайте, чтобы повернуть её, затем коснитесь **Confirm** или **Cancel** (или нажмите Esc).

Две фигуры, соединённые гранью к грани, точно делят эту грань — например, куб на кубе.

### Присоедините фигуру к вершине

1. Коснитесь **подсвеченной вершины**. Подсвечиваются только свободные вершины. Фигуры, к которым ещё есть куда пристраивать, светятся.
2. Коснитесь **Attach via vertex…** и выберите любую фигуру. Соединение по вершине принимает любую фигуру.
3. Поверните её и коснитесь **Confirm**, так же как при присоединении к грани.

### Отмена и удаление

- **Undo** (↶, верхняя панель) отменяет ваше последнее изменение любого вида: присоединение, удаление, Transform, шаг 4D-постройки, Start over или импорт. Коснитесь ещё раз, чтобы отступить дальше, или удерживайте, чтобы отмотать сразу несколько шагов.
- Выберите фигуру и коснитесь **Delete**, чтобы убрать её вместе со всем, что построено поверх неё.

## Просмотр каталога

**Браузер фигур** (◈ на угловом колесе) — это галерея. В нём есть вкладки:

- **Главная:** семейства, а также недавно просмотренные и избранные фигуры.
- **Поиск:** ищите по названию (попробуйте «J12» или «gyrobicupola») или фильтруйте по семейству, форме грани и количеству граней.
- **Сцена:** то, что вы уже построили.
- **Избранное:** фигуры, отмеченные звёздочкой.

Коснитесь любой фигуры, чтобы увидеть подробности: вершины, рёбра, грани и коннекторы. Оттуда можно:

- **Добавить в сцену:** начать строить с этой фигурой.
- **В избранное:** отметить её звёздочкой.
- **Добавить к сравнению:** поставить рядом до четырёх фигур.
- **Смотреть 4D:** для фигур с поддержкой 4D — показать 4D-многогранник, в который она продолжается.

### Семейства

| Семейство | Что в нём |
|---|---|
| Deltahedra | 8 выпуклых тел только из правильных треугольников |
| Platonic | 5 правильных тел |
| Archimedean | 13 полуправильных тел |
| Johnson | 92 выпуклых тела с правильными гранями |
| Catalan | Двойственные к архимедовым телам |
| Prisms, Antiprisms | Два многоугольника, соединённые поясом из квадратов или треугольников |
| 4D-Capable | Фигуры, которые замыкаются в правильный 4D-многогранник |
| Parallelohedra | Фигуры, заполняющие пространство одними параллельными переносами |
| Space-Filling Pairs | Две фигуры, вместе заполняющие пространство |
| Miscellaneous | Ступенчатые пирамиды, соединительные детали и удлинители призм |

Звёздчатые многогранники тоже перечислены. Они только для справки и не годятся для построек, потому что их грани проходят сквозь друг друга.

## Рассматривайте постройку

Касайтесь **View**, чтобы перебирать три режима:

- **Solid:** обычные грани.
- **Translucent:** прозрачные грани.
- **Skeleton:** только рёбра, чтобы видеть внутренность вложенных структур.

Когда группа деталей замыкается в полную клетку, появляется **Closed cage!**. У некоторых известных сочетаний есть собственное название, например Stella Octangula. Коснитесь **i** рядом с названием, чтобы прочитать описание.

## Постройка в 4D

Некоторые фигуры — строительные блоки правильного 4D-многогранника, например куб (тессеракт) или додекаэдр (120-ячейник). Когда вы выбираете такую фигуру, появляется переключатель **3D / 4D**.

1. Выберите фигуру и коснитесь **4D**. Если она может замкнуться в несколько многогранников, выберите один.
2. Касайтесь **Add next cell**, чтобы по одной добавлять ячейки вокруг первой. **Remove last cell** убирает одну.
3. Когда первая оболочка готова, **Build next shell** добавляет сразу целый слой. **Remove last shell** убирает слой.
4. Счётчик показывает, сколько ячеек из общего числа вы построили.

На что посмотреть во время постройки:

- **Open / Closed:** Open показывает каждую ячейку как обычную неискажённую копию, и виден настоящий зазор между ними. Closed показывает каждую ячейку изогнутой на её истинное место в 4D-структуре. Переключатель блокируется, как только вы строите вторую оболочку, потому что она зависит от того, что первая замкнута.
- **RCP-Coordinates:** показывает фиолетовой точкой ту точку, из которой порождается каждая ячейка.
- **Shell colours:** раскрашивает каждую оболочку по-своему, чтобы соседние оболочки различались.

Коснитесь **3D**, чтобы вернуть обычные элементы управления. Ваша 4D-постройка сохраняется.

Некоторые фигуры можно также присоединять через **Attach via Duoprism…**: точная копия соединяется через призму — это построение 4D Prism.

## Сохранение работы

- **Save:** сохраняет постройку в этом браузере. Она возвращается, когда вы снова открываете сайт на том же устройстве и в том же браузере.
- **File → Export JSON:** скачивает постройку файлом — для резервной копии или чтобы перенести её на другое устройство.
- **File → Import JSON…:** открывает файл, экспортированный ранее. Он заменяет то, что на экране, а **Undo** это отменяет.
- **What's New:** последние изменения.
- **Язык:** воспользуйтесь переключателем 🌐 вверху экрана приветствия или этого руководства либо коснитесь грани 🌐 на угловом колесе, чтобы перейти к следующему языку. Языков 7, и все эти места переключаются вместе.

# Справочник по управлению

## Верхняя панель

| Элемент | Что делает |
|---|---|
| i | Описание сочетания, у которого есть название |
| What's New | Последние изменения |
| View | Переключает Solid, Translucent и Skeleton |
| ↶ Undo | Отменяет последнее изменение любого вида. Коснитесь ещё раз, чтобы отступить дальше; удерживайте, чтобы отмотать несколько шагов |
| Save | Сохраняет постройку в этом браузере |
| File ▾ | Export JSON, Import JSON… |

## Контекстная панель

Эти элементы меняются в зависимости от того, что выбрано.

| Когда | Элементы |
|---|---|
| Выбрана фигура | Transform to… (если у фигуры есть родственная форма), Delete, Attach via face…, Attach via Duoprism… |
| Выбрана вершина | Attach via vertex… |
| Выбрана фигура с поддержкой 4D | 3D / 4D, а в 4D: Add next cell, Remove last cell, Build next shell, Remove last shell, Open / Closed, RCP-Coordinates, Shell colours |
| Новая фигура ждёт размещения | Confirm, Cancel (Esc) |

## Угловое колесо

Маленький додекаэдр в углу. Перетаскивайте, чтобы повернуть его, и касайтесь грани.

| Символ | Элемент |
|---|---|
| ◐ | Открыть или закрыть колесо фигур |
| ◈ | Открыть или закрыть браузер фигур |
| ⛶ | Режим просмотра |
| ▣ | Save |
| ℹ | About (снова открывает экран приветствия) |
| 🌐 | Переключить на следующий язык (показывает название текущего) |

## Клавиатура и мышь

| Ввод | Действие |
|---|---|
| Щелчок по фигуре | Выбрать её вместе с гранью, по которой вы щёлкнули |
| Щелчок по вершине | Выбрать её для присоединения к вершине |
| Перетаскивание левой кнопкой | Повернуть камеру или повернуть новую фигуру до подтверждения |
| Колёсико мыши | Масштаб |
| Tab или Пробел | Открыть колесо фигур |
| Esc | Отменить размещение фигуры или закрыть колесо |

## Сенсорный экран

| Жест | Действие |
|---|---|
| Касание вершины или фигуры | Выбрать её |
| Перетаскивание одним пальцем | Повернуть камеру или повернуть новую фигуру |
| Сведение пальцев | Масштаб |
