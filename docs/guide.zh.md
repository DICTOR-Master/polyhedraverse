# Polyhedraverse 用户指南

Polyhedraverse 和它的孪生网站 [Rhombiverse](https://rhombiverse.vercel.app) 是观察同一种几何的两种方式。Rhombiverse 是**风景**：向四面八方延伸的晶格本身。Polyhedraverse 是**肖像画廊**：住在这些晶格里的形状，一次一个，近距离展示。第三个姊妹站点 [Kaleidohedra](https://kaleidohedra.vercel.app) **让风景动起来**：可以剪切、滑动晶格，每一块都随之移动。

这里没有晶格。你从一个形状开始，把更多形状连接上去，顶点对顶点或面对面，结构就从形状本身生长出来。有些形状还可以一胞一胞地搭建成它真正的 4D 多胞体。

本指南的第一部分介绍常用操作，第二部分列出所有控件。

按钮名称按应用中显示的样子书写（应用尚未翻译的名称保留英文）。形状和家族的名称在所有语言中都保持原名。

## 入门

### 选择形状

1. 在欢迎界面按下 **ENTER**。
2. 轻点 **Start over with…**（或右上角的 ◈，或按 Tab 或空格）打开形状浏览器。
3. 在 **首页** 轻点一个家族、搜索形状，或轻点浏览器顶部的 **完整目录**，按家族查看所有形状。轻点一个形状查看详情，然后轻点 **添加到场景**。
4. 它会替换屏幕上已有的内容，让你从头开始。

### 移动镜头

- **旋转：** 单指拖动，或按住鼠标左键拖动。
- **缩放：** 双指捏合，或使用滚轮。

### 把形状连接到面上

1. 轻点一个形状的主体来选中它。你轻点的那个面也会被选中。
2. 轻点 **Attach via face…**。选择器只提供拥有同样大小面的形状。
3. 新形状出现了，但还没有固定。拖动来转动它，然后轻点 **Confirm**，或者 **Cancel**（或按 Esc）。

面对面连接的两个形状会完全共享那个面，例如一个立方体叠在另一个立方体上。

拖动会依次切换新形状贴在这个面上的所有摆法，并显示计数（“registration 3/8”）：面的每一种转向；如果新形状有同样大小但形状不同的面，还包括这些面各自的摆法，所以面不整齐的部件也总能按你想要的方式放好。例如搭 DICTO 的倾斜六棱柱：从正方形面块开始，把全菱形块贴到它的一个 72° 菱形上，拖动直到六边形面平齐，再用同样的方法贴上第二个正方形面块。

最贴合的放法排在前面：能同时贴合已搭好的零件两三个面的放法（嵌进角落）会排在只贴着所选面的放法之前，计数里也会显示（“registration 1/4 · 3 faces”）。会切入已搭零件的放法不会出现。对于能填满空间的形状，把它接到同样的形状上时，会先放在延续铺排的位置。与邻居贴合的面算作已用，不会再出现。

### 把形状连接到顶点上

1. 轻点一个**高亮的顶点**。只有空闲的顶点会亮起。还有空间继续搭建的形状会发光。
2. 轻点 **Attach via vertex…**，然后选择任意形状。顶点连接接受任何形状。
3. 和面连接一样，转动它并轻点 **Confirm**。

### 撤销和删除

- **Undo**（↶，顶部栏）撤销你最近的任何一种更改：一次连接、一次删除、一次 Transform、一个 4D 搭建步骤、Start over 或一次导入。再轻点一次可以继续回退，按住可以一次回退好几步。
- 选中一个形状并轻点 **Delete** 就能移除它，连同搭建在它上面的所有东西。

## 浏览目录

**形状浏览器**（右上角的 ◈）就是画廊；顶部的 **完整目录** 按家族显示所有形状。它有这些标签页：

- **首页：** 各个家族，以及你最近浏览过的形状和收藏。
- **搜索：** 按名称搜索（试试“J12”或“gyrobicupola”），或按家族、面的形状和面数筛选。
- **场景：** 你目前搭建的内容。
- **收藏：** 你加了星标的形状。

轻点任意形状可以查看详情：顶点、边、面和连接点。在那里你可以：

- **添加到场景：** 用它开始搭建。
- **收藏：** 给它加星标。
- **添加到比较：** 最多把四个形状并排比较。
- **查看4D：** 对支持 4D 的形状，显示它延伸成的 4D 多胞体。
- **展开图：** 查看形状平展开来的样子，用滑块或**折起**把它折回立体，并可**下载 PDF（A4）**打印：剪实线，折虚线，把相同数字的边粘在一起。**粘贴舌片**为每对需粘合的边加一个舌片。星形没有展开图。

**3D+ Bridges** 中的形状还会在详情里说明它连接到哪个更高维的多胞体（例如菱形十二面体是 tesseract 和 24-cell 的影子）。

### 家族

| 家族 | 内容 |
|---|---|
| Deltahedra | 只由等边三角形构成的 8 种凸多面体 |
| Platonic | 5 种正多面体 |
| Archimedean | 13 种半正多面体 |
| Johnson | 92 种面为正多边形的凸多面体 |
| Catalan | 阿基米德立体的对偶 |
| Stellations | 为柏拉图立体和卡塔兰立体准备的部件，各自贴合一个面：平面型（棱锥连成新的凸立体，例如由正四面体得到立方体），以及该立体真正具有的星形化，直到第三个。在每个面上放一个部件就能精确搭出该星形化，例如正十二面体的小星形、大、大星形十二面体 |
| Prisms、Antiprisms | 由一圈正方形或三角形连接起来的两个多边形 |
| 4D Polytopes | 按对称性排列的六个正 4D 多胞体（5、8、16、24、120、600 胞体）；打开一个并点“逐胞搭建”，就会放下它的种子胞并开始逐胞搭建 |
| Parallelohedra | 只靠平移就能填满空间的形状：费奥多罗夫五种及其变体（菱面体，以及 DICTO 用 Zometool 发现的倾斜六棱柱和它的两个块，以及斜菱形十二面体和它的扁菱面体），然后是经 Kaleidohedra 验证的（贝恩拉伸下所有棱等长的胞体：贝恩菱形十二面体、早已为人所知且由 DICTO 独立得到的正六边形伸长十二面体，以及 DICTO 的贝恩伸长十二面体），然后是 Kaleidohedra Regular 9（所有棱等长、面只有正方形、正六边形和 60° 菱形的空间填充形状） |
| Space-Filling Pairs | 两个一起填满空间的形状，包括 DICTO 的龙宝石与星形八面体（来自 Kaleidohedra），二者的面可以彼此相接，菱形与彭罗斯粗菱形相合；还有 Sunstar Lattice 这一对：犬星（正十二面体最密堆积留下的空洞，棱长全为黄金比的八角星，体积 φ/2）与在犬星接触处加了接缝的正十二面体，在其面上接上 6 个犬星就成为太阳星 |
| Aperiodic Sets | 两对非周期块：长形和扁形黄金菱面体（3D 彭罗斯镶嵌），以及粗、细彭罗斯菱形棱柱（分层的 5D 镶嵌） |
| 3D+ Bridges | 是更高维多胞体的影子、截面、胞或角的形状；详情里写明是哪一种 |
| Miscellaneous | 分级棱锥、连接件和棱柱延长件 |

星形多面体也列在其中。它们的面会互相穿过，所以不能连接，但其中三个可以搭出来：在正十二面体的每个面上放一个 **Stellations** 部件，就得到小星形十二面体（部件 2）、大十二面体（3）或大星形十二面体（4）。

## 查看你的作品

轻点 **View** 可以在三种模式间循环：

- **Solid：** 普通的面。
- **Translucent：** 半透明的面。
- **Skeleton：** 只显示边，可以看到嵌套结构的内部。

点按 **🎨**（Colour） 选择部件的着色方式：**Green**（全部绿色，默认）、**Family**（每个部件用其家族的颜色，菜单中有图例）或 **Pick**（从 14 种颜色中选择；新部件使用该颜色，**Paint** 可为选中的部件重新上色）。选定的颜色会随作品一起保存。

当一组部件闭合成一个完整的笼子时，会出现 **Closed cage!**。一些著名的排列有自己的名字，比如 Stella Octangula。轻点名字旁边的 **i** 可以查看说明。

## 在 4D 中搭建

有些形状是正 4D 多胞体的构件，例如立方体（超正方体）或十二面体（正一百二十胞体）。选中这类形状时，会出现 **3D / 4D** 开关。

1. 选中形状并轻点 **4D**。如果它能闭合成不止一种多胞体，请选择其中一个。
2. 轻点 **Add next cell**，在第一个胞周围一个一个地添加胞。**Remove last cell** 撤回一个。
3. 第一层壳完成后，**Build next shell** 一次添加一整层。**Remove last shell** 去掉一层。
4. 计数器显示你已经搭建了总数中的多少个胞。

搭建时值得留意的内容：

- **Open / Closed：** Open 把每个胞显示为普通的、不变形的副本，可以看到它们之间真实的缝隙。Closed 把每个胞弯折到它在 4D 结构中的真正位置。一旦你搭建了第二层壳，这个开关就会锁定，因为那层壳依赖于第一层已经闭合。
- **RCP-Coordinates：** 用紫色的点显示每个胞的生成点。
- **Shell colours：** 为每层壳着不同颜色，让相邻的壳容易区分。

轻点 **3D** 可以回到普通控件。你的 4D 作品会保留。

有些形状还可以使用 **Attach via Duoprism…**，它通过一个棱柱连接一个完全相同的副本，也就是 4D Prism 构造。

## 黄金菱面体

当你的作品全部由黄金菱面体组成时，一个条会显示有多少块符合真正的 3D 彭罗斯镶嵌。**Next safe piece** 添加一块让作品留在该镶嵌之内，所以永远不会卡住。**Next step** 一块一块地搭出所选的黄金形状（比林斯基十二面体、菱形二十面体或菱形三十面体）。**File** 也能载入每个完成的黄金作品，供你拆开或扩展。Undo 逐步撤销。

## 保存你的作品

- **Save：** 把作品保存在这个浏览器中。在同一台设备、同一个浏览器上重新打开网站，它就会回来。
- **File → Export JSON：** 把作品下载为文件，用来备份或转移到另一台设备。
- **File → Import JSON…：** 打开你之前导出的文件。它会替换屏幕上的内容，**Undo** 可以撤销。
- **What's New：** 最近的更改。
- **语言：** 使用欢迎界面或本指南顶部的 🌐 选择器，或轻点右上角的 🌐 切换到下一种语言。共有 7 种语言，这些位置始终保持一致。

# 控件参考

## 顶部栏

| 控件 | 作用 |
|---|---|
| i | 已命名排列的说明 |
| What's New | 最近的更改 |
| View | 在 Solid、Translucent 和 Skeleton 之间循环 |
| 🎨 Colour | Green、Family 或 Pick 着色；Pick 模式下可选 14 种颜色 |
| ↶ Undo | 撤销你最近的任何一种更改。再轻点继续回退；按住可回退好几步 |
| Save | 把作品保存在这个浏览器中 |
| File ▾ | Export JSON、Import JSON…，以及完成的黄金作品 |
| Start over with… | 打开形状浏览器，用一个形状重新开始（Tab 或空格） |

## 上下文栏

这些控件会随你选中的内容而变化。

| 何时 | 控件 |
|---|---|
| 选中了一个形状 | Transform to…（当形状有相关形态时）、Delete、Attach via face…、Attach via Duoprism… |
| 选中了一个顶点 | Attach via vertex… |
| 选中了支持 4D 的形状 | 3D / 4D，在 4D 中还有：Add next cell、Remove last cell、Build next shell、Remove last shell、Open / Closed、RCP-Coordinates、Shell colours |
| 有新形状等待放置 | Confirm、Cancel (Esc) |

## 工具（右上角）

3D 视图右上角的一列按钮。

| 符号 | 控件 |
|---|---|
| ◈ | 打开或关闭形状浏览器 |
| 3D / ∥ / ISO | 投影：透视、平行（正交）或等轴测（轻点切换） |
| ℹ | About（重新打开欢迎界面） |
| 🌐 | 切换到下一种语言（显示当前语言的代码） |

## 键盘和鼠标

| 输入 | 操作 |
|---|---|
| 点击一个形状 | 选中它，以及你点击的那个面 |
| 点击一个顶点 | 选中它，用于顶点连接 |
| 左键拖动 | 旋转镜头，或在确认前转动新形状 |
| 滚轮 | 缩放 |
| Tab 或空格 | 打开形状浏览器（Start over with…） |
| Esc | 取消放置形状 |

## 触屏

| 手势 | 操作 |
|---|---|
| 轻点顶点或形状 | 选中它 |
| 单指拖动 | 旋转镜头，或转动新形状 |
| 双指捏合 | 缩放 |
