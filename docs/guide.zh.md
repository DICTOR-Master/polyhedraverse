# Polyhedraverse 用户指南

Polyhedraverse 和它的孪生网站 [Rhombiverse](https://rhombiverse.vercel.app) 是观察同一种几何的两种方式。Rhombiverse 是**风景**：向四面八方延伸的晶格本身。Polyhedraverse 是**肖像画廊**：住在这些晶格里的形状，一次一个，近距离展示。

这里没有晶格。你从一个形状开始，把更多形状连接上去，顶点对顶点或面对面，结构就从形状本身生长出来。有些形状还可以一胞一胞地搭建成它真正的 4D 多胞体。

本指南的第一部分介绍常用操作，第二部分列出所有控件。

按钮名称按应用中显示的样子书写（应用尚未翻译的名称保留英文）。形状和家族的名称在所有语言中都保持原名。

## 入门

### 选择形状

1. 在欢迎界面按下 **ENTER**。
2. 按 **Tab** 或 **空格**，或轻点 **形状轮盘** 按钮，打开形状轮盘。
3. 轮盘是一个十二面体，每个面是一个形状家族。拖动可以转动它（也可以用方向键），轻点一个面就会打开那个家族。将鼠标悬停在面上或长按，可以看到名称。在家族里面，**Home** 面（六边形里的 H）会带你回到家族列表。
4. 轻点一个形状。它会替换屏幕上已有的内容，让你从头开始。

**转动轮盘** 会随机选一个家族。

### 移动镜头

- **旋转：** 单指拖动，或按住鼠标左键拖动。
- **缩放：** 双指捏合，或使用滚轮。

### 把形状连接到面上

1. 轻点一个形状的主体来选中它。你轻点的那个面也会被选中。
2. 轻点 **Attach via face…**。选择器只提供拥有同样大小面的形状。
3. 新形状出现了，但还没有固定。拖动来转动它，然后轻点 **Confirm**，或者 **Cancel**（或按 Esc）。

面对面连接的两个形状会完全共享那个面，例如一个立方体叠在另一个立方体上。

### 把形状连接到顶点上

1. 轻点一个**高亮的顶点**。只有空闲的顶点会亮起。还有空间继续搭建的形状会发光。
2. 轻点 **Attach via vertex…**，然后选择任意形状。顶点连接接受任何形状。
3. 和面连接一样，转动它并轻点 **Confirm**。

### 撤销和删除

- **Undo**（↶，顶部栏）撤销你最近的任何一种更改：一次连接、一次删除、一次 Transform、一个 4D 搭建步骤、Start over 或一次导入。再轻点一次可以继续回退，按住可以一次回退好几步。
- 选中一个形状并轻点 **Delete** 就能移除它，连同搭建在它上面的所有东西。

## 浏览目录

**形状浏览器**（角落轮盘上的 ◈）就是画廊。它有这些标签页：

- **首页：** 各个家族，以及你最近浏览过的形状和收藏。
- **搜索：** 按名称搜索（试试“J12”或“gyrobicupola”），或按家族、面的形状和面数筛选。
- **场景：** 你目前搭建的内容。
- **收藏：** 你加了星标的形状。

轻点任意形状可以查看详情：顶点、边、面和连接点。在那里你可以：

- **添加到场景：** 用它开始搭建。
- **收藏：** 给它加星标。
- **添加到比较：** 最多把四个形状并排比较。
- **查看4D：** 对支持 4D 的形状，显示它延伸成的 4D 多胞体。

### 家族

| 家族 | 内容 |
|---|---|
| Deltahedra | 只由等边三角形构成的 8 种凸多面体 |
| Platonic | 5 种正多面体 |
| Archimedean | 13 种半正多面体 |
| Johnson | 92 种面为正多边形的凸多面体 |
| Catalan | 阿基米德立体的对偶 |
| Prisms、Antiprisms | 由一圈正方形或三角形连接起来的两个多边形 |
| 4D-Capable | 能闭合成正 4D 多胞体的形状 |
| Parallelohedra | 只靠平移就能填满空间的形状 |
| Space-Filling Pairs | 两个一起填满空间的形状 |
| Miscellaneous | 分级棱锥、连接件和棱柱延长件 |

星形多面体也列在其中。它们仅供参考，不能用来搭建，因为它们的面会互相穿过。

## 查看你的作品

轻点 **View** 可以在三种模式间循环：

- **Solid：** 普通的面。
- **Translucent：** 半透明的面。
- **Skeleton：** 只显示边，可以看到嵌套结构的内部。

当一组部件闭合成一个完整的笼子时，会出现 **Closed cage!**。一些著名的排列有自己的名字，比如 Stella Octangula。轻点名字旁边的 **i** 可以查看说明。

## 在 4D 中搭建

有些形状是正 4D 多胞体的构件，例如立方体（超正方体）或十二面体（正一百二十胞体）。选中这类形状时，会出现 **3D / 4D** 开关。

1. 选中形状并轻点 **4D**。如果它能闭合成不止一种多胞体，请选择其中一个。
2. 轻点 **Add next cell**，在第一个胞周围一个一个地添加胞。**Remove last cell** 撤回一个。
3. 第一层壳完成后，**Build next shell** 一次添加一整层。**Remove last shell** 去掉一层。
4. 计数器显示你已经搭建了总数中的多少个胞。

搭建时值得留意的内容：

- **Open / Closed：** Open 把每个胞显示为普通的、不变形的副本，可以看到它们之间真实的缝隙。Closed 把每个胞弯折到它在 4D 结构中的真正位置。一旦你搭建了第二层壳，这个开关就会锁定，因为那层壳依赖于第一层已经闭合。
- **RCP-Coordinates：** 用紫色的点显示每个胞的生成点。
- **Shell colours：** 为每层壳着不同颜色，让相邻的壳容易区分。

轻点 **3D** 可以回到普通控件。你的 4D 作品会保留。

有些形状还可以使用 **Attach via Duoprism…**，它通过一个棱柱连接一个完全相同的副本，也就是 4D Prism 构造。

## 保存你的作品

- **Save：** 把作品保存在这个浏览器中。在同一台设备、同一个浏览器上重新打开网站，它就会回来。
- **File → Export JSON：** 把作品下载为文件，用来备份或转移到另一台设备。
- **File → Import JSON…：** 打开你之前导出的文件。它会替换屏幕上的内容，**Undo** 可以撤销。
- **What's New：** 最近的更改。
- **语言：** 使用欢迎界面或本指南顶部的 🌐 选择器，或轻点角落轮盘上的 🌐 面切换到下一种语言。共有 7 种语言，这些位置始终保持一致。

# 控件参考

## 顶部栏

| 控件 | 作用 |
|---|---|
| i | 已命名排列的说明 |
| What's New | 最近的更改 |
| View | 在 Solid、Translucent 和 Skeleton 之间循环 |
| ↶ Undo | 撤销你最近的任何一种更改。再轻点继续回退；按住可回退好几步 |
| Save | 把作品保存在这个浏览器中 |
| File ▾ | Export JSON、Import JSON… |

## 上下文栏

这些控件会随你选中的内容而变化。

| 何时 | 控件 |
|---|---|
| 选中了一个形状 | Transform to…（当形状有相关形态时）、Delete、Attach via face…、Attach via Duoprism… |
| 选中了一个顶点 | Attach via vertex… |
| 选中了支持 4D 的形状 | 3D / 4D，在 4D 中还有：Add next cell、Remove last cell、Build next shell、Remove last shell、Open / Closed、RCP-Coordinates、Shell colours |
| 有新形状等待放置 | Confirm、Cancel (Esc) |

## 角落轮盘

角落里的小十二面体。拖动来转动它，轻点一个面。

| 符号 | 控件 |
|---|---|
| ◐ | 打开或关闭形状轮盘 |
| ◈ | 打开或关闭形状浏览器 |
| ⛶ | 视图模式 |
| ▣ | Save |
| ℹ | About（重新打开欢迎界面） |
| 🌐 | 切换到下一种语言（显示当前语言名称） |

## 键盘和鼠标

| 输入 | 操作 |
|---|---|
| 点击一个形状 | 选中它，以及你点击的那个面 |
| 点击一个顶点 | 选中它，用于顶点连接 |
| 左键拖动 | 旋转镜头，或在确认前转动新形状 |
| 滚轮 | 缩放 |
| Tab 或空格 | 打开形状轮盘 |
| Esc | 取消放置形状，或关闭轮盘 |

## 触屏

| 手势 | 操作 |
|---|---|
| 轻点顶点或形状 | 选中它 |
| 单指拖动 | 旋转镜头，或转动新形状 |
| 双指捏合 | 缩放 |
